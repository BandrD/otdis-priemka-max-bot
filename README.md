# OTDIS · MAX-бот приёмной комиссии

правила поступления, документы, направления, вступительные испытания — по сценарию из ТЗ,

## Зачем бот

Приёмная комиссия получает одни и те же вопросы: кто может поступить, какие документы, когда экзамен, есть ли общежитие. Бот ведёт абитуриента **кнопочным меню** (как в приложении к ТЗ) и не заставляет искать ответ на сайте.

| Кому | Что даёт |
|---|---|
| Абитуриенту | Быстрые ответы по сценарию + «Назад» |
| Если пункта нет | Ссылка на FAQ otdis.ru или вопрос GigaChat |
| Приёмной | Единая витрина типовых ответов |

Сайт: [otdis.ru](https://www.otdis.ru/)

## Что умеет

| | Раздел | Содержание |
|---:|---|---|
| 1 | Правила поступления | 9 класс, ОВЗ, льготы, первоочередное право |
| 2 | Приёмная комиссия | Сроки, график, документы, лично/онлайн, контакты |
| 3 | Вступительные испытания | Рисунок / живопись + даты; критерии на сайте |
| 4 | Зачисление | Бюджет / платно, сроки обучения, рейтинги |
| 5 | Направления | Швейный, банк, дизайн, реклама |
| 6 | Доп. вопросы | Общежитие, подготовительные курсы |
| 7 | Вне сценария | GigaChat (если ключ включён) |

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# MAX_BOT_TOKEN=...
python -m app.main --mode polling
```

| Режим | Команда |
|---|---|
| Long polling | `python -m app.main --mode polling` |
| Webhook | `python -m app.main --mode webhook` → `POST /max/webhook` |

| Переменная | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | токен MAX |
| `GIGACHAT_ENABLED` / `GIGACHAT_CREDENTIALS` | ИИ вне сценария |
| `DIALOG_TREE_PATH` | JSON-сценарий |

Без ключа GigaChat меню и ссылки работают как обычно.

```bash
pytest -q
```
